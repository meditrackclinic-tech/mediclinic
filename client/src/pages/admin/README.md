# Admin Pages

Admin pages are for system-level users who manage staff access, roles, sessions, email delivery, reports, and audit activity.

Current page:

- `AdminDashboard.jsx`: Admin page container with tabs.
- `AdminOverviewPage.jsx`: Live technical dashboard for staff accounts, sessions, password status, email status, and security checks.
- `AdminUsersPage.jsx`: Live staff creation, role and access management, password resets, and protected permanent deletion.
- `AdminReportsPage.jsx`: Live system and security report without clinical detail exposure.
- `AdminAuditLogsPage.jsx`: Audit and accountability activity.
