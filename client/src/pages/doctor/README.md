# Doctor Pages

Doctor pages are for clinicians who review structured symptom records and temporal tracking views.

Current page:

- `DoctorDashboard.jsx`: Doctor page container with tabs.
- `DoctorOverviewPage.jsx`: Main clinician review workspace.
- `DoctorPatientReviewPage.jsx`: Patient search and structured symptom review.
- `DoctorSymptomTimelinePage.jsx`: Temporal symptom tracking page.
- `DoctorReportsPage.jsx`: Placeholder page for clinical review reports.
